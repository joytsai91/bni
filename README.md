# BNI 分會管理系統

用 Google 試算表存資料、Google Apps Script 做網頁，不用租主機。分會幹部用手機或平板就能操作。

| 功能 | 內容 |
| --- | --- |
| 會員簽到 | 例會當天點一下名字就簽到，超過遲到時間自動記 L；可改代理（含代理人）、病假、缺席；一鍵把未簽到者記缺席；產生出席結果文字 |
| 來賓報名 | 公開報名表；每位會員有個人邀請連結（邀請人自動帶入）與 QR code；秘書可代為登記；現場來賓、簽到、繳費 |
| 列印 | 會員簽到表、來賓簽到表（含空白列）、來賓名牌（尺寸可調，A4 排版沿虛線裁切）、來賓桌牌與會員桌牌（A4 對折，兩面都看得到） |
| PALMS | 上傳 BNI Connect 匯出的報表（Excel / CSV），自動辨識欄位與期間 → 會員統計（缺席提醒）→ 一鍵產生 LINE 週報 |
| 設定 | 分會名稱、例會星期與時間、遲到判定時間、來賓費用、名牌尺寸、缺席提醒次數 |

## 部署（約 10 分鐘）

1. 建立一份 Google 試算表，例如「BNI ○○分會 管理」。
2. 試算表選單「擴充功能 → Apps Script」。
3. 把程式放進去，二選一：
   - **clasp（建議）**：`npm i -g @google/clasp` → `clasp login` → 把 `.clasp.json.example` 複製成 `.clasp.json`，填入 Apps Script「專案設定」裡的指令碼 ID → `clasp push`。
   - **手動**：`src/` 裡每個 `.js` 在編輯器建立同名的指令碼檔，每個 `.html` 建立同名的 HTML 檔，內容整份貼上。到「專案設定」勾選「在編輯器中顯示 appsscript.json」，再貼上 `src/appsscript.json`。
4. 回到試算表重新整理，選單會出現「BNI 分會工具」：
   - 「初始化資料表」：第一次會要求授權。
   - 「設定管理密碼」：至少 6 碼，簽到、列印、PALMS 都用這組密碼登入。
5. Apps Script 編輯器「部署 → 新增部署 → 類型：網頁應用程式」：執行身分選「我」，存取權選「所有人」。
6. 試算表選單「BNI 分會工具 → 顯示系統網址」，取得管理系統與來賓報名網址。

程式更新後，到「部署 → 管理部署」編輯既有部署並選「新版本」，網址就不會變。

## 每週流程

- **例會前**：在「來賓」分頁複製報名連結（或會員個人邀請連結）貼到 LINE。來賓填完就會出現在名單裡。到「列印」分頁印名牌、桌牌與簽到表。
- **例會中**：用平板開「簽到」分頁，會員到場點名字，來賓按「簽到」「已繳費」。臨時來的來賓按「＋ 現場來賓」。
- **例會後**：按「未簽到者記缺席」，再按「出席結果文字」複製給秘書或貼到 LINE。
- **PALMS**：從 BNI Connect 匯出 PALMS 報表，在「PALMS」分頁上傳，確認期間後儲存，再按「LINE 週報」。

## 資料表（都在同一份試算表）

| 工作表 | 說明 |
| --- | --- |
| 設定 | 分會設定，也可以在管理系統的「設定」分頁修改 |
| 會員名單 | 直接在試算表維護。會員ID 留空會自動補；狀態填「離會」「休會」「停權」就不會出現在簽到與列印。列印順序就是名單順序 |
| 來賓名單 | 報名表、代為登記、現場來賓都會寫進這裡 |
| 會員出席 | 每場例會每位會員一列（P 出席、L 遲到、S 代理、M 病假、A 缺席） |
| PALMS | 每一期（起訖日期）一批資料，同一期重新匯入會覆蓋 |

欄位依標題對應：在試算表裡調整欄位順序、在右邊加自己的欄位都沒關係，但不要改標題文字。

## 安全

- 管理功能都要管理密碼。密碼存在 Apps Script 的指令碼屬性，不在試算表裡；連續輸錯 30 次會暫停 10 分鐘。
- 來賓報名頁是公開的：只能新增報名，只看得到會員姓名與專業別（邀請人選單用）。有防機器人欄位，也有送出次數上限。
- 來賓填的內容寫進試算表前會轉成純文字，不會被當成公式執行；顯示在畫面上時也會跳脫，不會被當成 HTML。
- Excel 解析用 SheetJS 官方 CDN 的 0.20.3（npm 上的 0.18.5 有已知漏洞，只在本機開發測試時使用）。

## 開發

```bash
npm install
npm test        # 核心邏輯與後端流程測試（用 dev/gas-fake.js 模擬 Google 試算表）
npm run dev     # 本機預覽 http://127.0.0.1:8080/exec（管理密碼 1234，含示範資料）
npm run e2e     # 用 Chromium 實際操作畫面，輸出截圖與列印 PDF 到 .e2e-output/
```

`dev/gas-fake.js` 會模擬試算表的自動轉型：沒處理好的電話會掉開頭 0、日期字串會變日期、公式字串會直接報錯。寫入相關的程式改壞了，測試抓得到。

## 尚未完成

- **BNI Connect 自動抓取 PALMS**：要先確認 BNI Connect 的登入流程與報表網址才能實作。如果登入有驗證碼或兩步驟驗證，Apps Script 無法自動登入，就維持「上傳匯出檔」。目前請用上傳。
- 實際 BNI Connect 匯出檔的欄位，還要拿真實檔案確認。解析器已支援常見的英文與中文標題，上傳預覽時也會列出「辨識到的欄位」與「未使用的欄位」，方便核對。
